# 🛢️ Ruta de Lubricación — Registro Semanal

Aplicación web hecha con [Streamlit](https://streamlit.io) para el registro semanal
de la ruta de lubricación. Lee la plantilla maestra de Excel y guarda los registros
en un archivo de datos.

## 📁 Archivos

| Archivo | Descripción |
|---|---|
| `app.py` | Aplicación principal (Streamlit) |
| `RUTA LUB V2 OCT 2026.xlsx` | Plantilla maestra con la ruta semanal y checklists |

## ▶️ Cómo ejecutarla

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 🌐 Desplegar gratis en la nube

Puedes publicarla gratis en **Streamlit Community Cloud** (streamlit.io/cloud):
1. Sube este repositorio a GitHub.
2. Entra a [share.streamlit.io](https://share.streamlit.io) con tu cuenta de GitHub.
3. Elige el repositorio → archivo principal: `app.py` → **Deploy**.

Así cualquiera podrá usarla desde el navegador sin instalar nada.
